# Yelbolt Colors

Color tokens from the Yelbolt design system. Unlike the other four themes, Yelbolt ships **seven color families** (`YLB`, `NTL`, `UICP`, `UNO`, `TCN`, `UICS`, `ISB`) instead of a single brand hue — each is an 8-step shade/tint ramp, and each has its own `{family}-{light,dark}` mode pair activated via `data-mode="yelbolt-{family}-{light,dark}"` (e.g. `data-mode="yelbolt-ylb-dark"`). Use CSS custom properties (e.g. `var(--color-background-brand-default)`) in your styles — see [docs/color-mode-gradation.md](../../../docs/color-mode-gradation.md) for the full derivation rule.

## YLB Mode — Semantic Tokens

`YLB` is the default brand family. Within a mode, `primary` / `secondary` / `tertiary` form a darkness gradient off that mode's own family, `brand` is a fixed saturated pivot, and `danger` / `success` / `warning` always borrow `TCN` / `UICS` / `ISB` respectively — see [docs/color-mode-gradation.md](../../../docs/color-mode-gradation.md) for the full rule. The other six families (`NTL`, `UICP`, `UNO`, `TCN`, `UICS`, `ISB`) follow the exact same derivation, swapping in their own ramp.
